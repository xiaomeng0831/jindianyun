## 1. 意图与背景（Intent & Why）
津电云已完成北洋园校区离线矢量底图、26 个充电站模拟/实时适配器、24h 趋势及 PWA 离线缓存。为进一步提升师生在校园内找桩的实战体验并打通线上部署与本地真实数据联调，本次升级聚焦三个方向：
1. **从“找楼”到“找最近空闲桩”**：师生搜宿舍/教学楼或点击定位时，系统不仅定位到楼宇，还能直接给出附近有空位的充电站并在地图上画出导引连线；
2. **宏观掌握全校负载**：一眼看清全校当前空闲/占用全貌，快速找到最空闲的站点，避开满载站点；
3. **数据源透明切换与工程闭环**：无需手改 URL 参数即可在界面切换“模拟数据 / 本地实时代理”，修复已知代理与哈希细节问题，并同步推送至 GitHub Pages。

## 2. 目标、非目标与反目标（Goals, Non-Goals & Anti-Goals）

### Goals（目标）
- **G1 智能最近空闲桩推荐与地图导引线**：选中任意楼宇、或点击地图「📍 附近寻桩」按钮（支持浏览器地理位置定位及校内默认/点选起点）时，结合球面距离（Haversine）与当前空闲插口数计算 Top 3 推荐站点；在 Canvas 上绘制起点锚点、起止点彩色虚线导引线与距离/空闲标签（如 `145m · 空闲 6 口`），并展示底部/浮动推荐卡片支持一键切换。
- **G2 全校充电状态总览看板**：在筛选栏右侧提供「📊 全校总览（空闲 X/Y）」入口，点击打开总览模态框/抽屉，展示全校总空闲率、自行车/汽车分类统计、**当前空闲最多 Top 5**、**满载预警站点**及锂电柜余量，点击任一站点直接定位并展开详情。
- **G3 可视化数据源切换 UI**：在总览看板/页脚提供数据源切换器（`模拟数据` vs `HTTP 实时代理`），支持配置/持久化代理 Endpoint（`localStorage`），并实时展示数据源状态（`模拟运行中` / `实时代理在线` / `代理离线·已回退模拟`）。
- **G4 隐患修复与线上发布**：
  - 修复 `scripts/cqt_proxy.mjs` 中 `/ NearDevice` 路径空格 bug；
  - 兼容 `.env` 中 `OPEN_ID`/`CQT_OPEN_ID` 与 `PHONENUMBER`/`CQT_PHONENUMBER` 两种命名，同时支持 `/api/charging/status` 与 `/api/stations` 双路由；
  - 统一 `js/panel.js` 与 `js/app.js` 的 URL 哈希格式（兼容 `#station=<id>` 与 `#station-<id>`）；
  - 扩展 `scripts/verify_all.mjs` 自动化测试覆盖新模块，提交并推送到 GitHub `origin/main` 触发 GitHub Pages 更新。

### Non-Goals（非目标）
- 不引入第三方地图 SDK（如高德/百度/Mapbox）或外部路由规划 API，校园内采用直线距离 + 步行折算系数（1.25x，约 80m/min）估算步行时间。
- 不将个人微信 `OPEN_ID` 打包到前端或推送到公共仓库。

### Anti-Goals（反目标）
- **绝不破坏零构建约束**：不引入 npm 前端依赖、打包器或框架，保持 `python3 -m http.server` 及 GitHub Pages 开箱即用。
- **绝不遮挡核心地图视野**：浮层与导引卡片必须紧凑、可随时一键关闭，移动端不得与底部详情抽屉发生层级冲突。

## 4. 核心技术设计（How It Gets Built）

1. **距离与推荐评分算法（`js/recommend.js` 或内置于 `js/app.js`）**：
   - `haversineMeters(lon1, lat1, lon2, lat2)`：计算两点间球面距离（米），步行耗时按 `Math.max(1, Math.round((meters * 1.25) / 80))` 分钟估算；
   - `recommendStations(origin, stations, detailReader, options)`：过滤当前分类（若选了自行车/汽车则按分类，否则默认优先自行车或全类），优先挑选 `idle > 0` 的站点，按综合距离评分 `score = meters - idle * 18`（兼顾距离近与空位充裕）排序，返回 Top 3 候选。
2. **Canvas 导引线渲染（`js/map.js`）**：
   - `MapView` 新增 `setGuideRoute(origin, targetStation, meta)` 与 `clearGuideRoute()`；
   - 在底图之上、站点图钉之下绘制：起点脉冲圆环、起点到目标站点的动态虚线弧线/直线、中点半透明胶囊标签（显示 `约 Xm · 步行 X 分钟`）。
3. **全校总览与数据源设置弹窗（`index.html` + `css/style.css` + `js/app.js`）**：
   - `#filter-bar` 新增汇总按钮 `.overview-trigger`（实时显示 `📊 总览 · 空闲 X`）；
   - 新增 `<dialog>` / 模态浮层 `#overview-modal`：顶部为全校自行车/汽车/锂电柜三大 KPI 卡片，中部为「空闲充裕榜 Top 5」与「高峰满载榜」双栏列表（点击即跳转对应站点），底部为「数据源模式切换（模拟 / HTTP 实时代理 + Endpoint 输入框 + 连通性检测）」。
4. **验证与部署**：
   - 在 `scripts/verify_all.mjs` 中新增第 6 项测试（距离计算、推荐排序算法、哈希解析与代理路由检查）；
   - 更新 `sw.js` 缓存版本号及 `PROGRESS.md` 记录，执行 `git push origin main`。
